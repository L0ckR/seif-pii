`common4`: BANK_CARD_NUMBER, EMAIL, NAME, PHONE_NUMBER. `supported8` дополнительно включает ADDRESS, CVC, INN, PASSPORT_NUMBER. Включаются целые примеры, у которых все gold-типы входят в заданное множество, и все отрицательные примеры; выбор не зависит от предсказаний. Исходные splits полностью прочитаны и проверены — 900 и 910 строк.

Гибрид здесь **PERSON-only**, как в исходном `scripts/evaluate_external.py`: используются те же сохранённые Presidio PERSON spans с фиксированным score 0.85 для обеих ревизий. LOCATION не добавляется. Исторический cache не содержит score; значение восстановлено по зафиксированной конфигурации spaCy/Presidio (пустые context и low-score списки). Модели не запускались, сетевые соединения блокировались. Это не проверка работающего HTTP-сервиса с PERSON+LOCATION.

Исходный `docs/pii-bench-comparison.json` независимо воспроизведён по старому cache: common4 и supported8, exact spans и typed characters, все три исторические системы, оба splits совпали точно. SHA256 корпуса, cache, подготовленного протокола проверены. Все Python-модули seif в двух деревьях совпадают с соответствующими Git-ревизиями; после вычисления это проверено повторно. Проверены 7240 точных восстановлений исходного текста.

По отдельным типам улучшились ADDRESS в domain и PASSPORT_NUMBER в обоих splits. Ухудшений precision, recall, F1, F2, exact cases и отрицательных примеров с FP нет ни на общих срезах, ни по отдельным domain/common4, ни по каждому поддерживаемому типу. Отдельная проверка каждого примера также не нашла регрессий; тексты ошибок не просматривались и не сохранялись в отчёте.

`report.json` содержит все метрики и условные paired-bootstrap интервалы; `summary.json` — основные показатели; `validation.json` — происхождение и проверки; `case-audit.json` — только агрегаты попарных изменений. `source-baseline.json` и `source-final.json` содержат полные SHA256 исходников. Предсказания содержат типы/смещения, без исходных текстов.

```bash
/tmp/seif-presidio-313/bin/python output/golden-improvements/external-pii-bench/runner.py --output /tmp/seif-pii-bench-reproduction
```

Это повторная проверка ранее использованного синтетического внешнего набора. Она не доказывает отсутствие регрессий на любых данных, не измеряет RPS и не заменяет независимый ещё не виденный benchmark. Typed-character метрика воспроизводит исходный протокол и включает все символы spans; она отличается от alphanumeric mask-метрики organizer golden. Bootstrap предполагает независимость примеров внутри domain и не учитывает зависимость синтетических шаблонов.

Runtime: `/tmp/seif-presidio-313/bin/python`, Python 3.13.7. Использованы локальные pyarrow 25.0.1 и numpy 2.4.6; из установленного presidio-analyzer 2.2.364 прочитаны исходники конфигурации для проверки постоянного NER score. Presidio/spaCy модели не запускались.
