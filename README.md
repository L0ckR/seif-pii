# СЕЙФ

**Данные работают. Личное остаётся личным.**

СЕЙФ — сервис защиты персональных данных в цепочке «пользователь → LLM → пользователь». Он распознаёт чувствительные данные, заменяет их на маски или синтетические значения, а затем при необходимости восстанавливает исходный текст.

## Возможности

- REST API и русскоязычная панель.
- 24 основных типа данных и дополнительный тип `LOCATION`.
- Режимы `mask`, `token` и `synthetic`.
- Точное восстановление исходного текста.
- Политики доступа для разных систем.
- Изолированные `payload_id`, TTL и лимиты запросов.
- Зашифрованное хранилище на Redis с AES-256-GCM.
- Аудит без сохранения исходного текста.
- Prometheus, Redis Sentinel и Kubernetes-манифесты.

Основной стек: Python 3.14.7 без GIL, FastAPI, Uvicorn, Redis и AES-256-GCM.

## Профили распознавания

Публичный `/process` сейчас работает в гибридном режиме с двумя GPU-репликами
RuBERT. В NER-сервисе и `compose.ner.yaml` RuBERT выбран по умолчанию.
Простой `make run` без NER запускает только правила; для CPU-хоста Presidio
включается отдельно через `compose.presidio.yaml`.

Доступные варианты:

- CPU-гибрид с Presidio для распознавания `PERSON` и `LOCATION`.
- GPU-профиль RuBERT с локальными весами и CUDA.
- Масштабирование API и NER через несколько реплик и общий Redis.

Внешние LLM, платные API и интернет во время обработки не требуются. При недоступности NER-сервиса hybrid-профиль возвращает ошибку, а не неполный результат.

Подробнее: [выбор стека](docs/stack.md), [сравнение с Presidio](docs/presidio.md), [запуск RuBERT](deploy/service/README.md#rubert-tensorrt).

## Демонстрация

На защите можно:

1. Передать текст с персональными данными.
2. Показать найденные типы, диапазоны и причины срабатывания.
3. Сравнить три режима защиты.
4. Восстановить исходный текст.

Все данные в демо вымышлены. Примеры показывают, как контекст влияет на распознавание: например, публичное упоминание поэта не считается персональными данными, а банковский адрес защищается.

## Быстрый запуск

Требуется `uv` и Python 3.14.7:

```bash
uv python install 3.14.7t
uv venv --python 3.14.7t
uv pip install -r requirements.lock
uv pip install -e '.[dev]'
make run
```

Интерфейс будет доступен по адресу `http://127.0.0.1:8765`.

Проверка состояния:

```text
GET /health
```

Для временного публичного URL с установленным `cloudflared`:

```bash
bash scripts/tunnel.sh
```

Quick Tunnel работает только пока запущены компьютер, сервис и туннель. Постоянный хостинг он не создаёт.
