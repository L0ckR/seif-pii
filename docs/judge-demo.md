# Короткая инструкция жюри

Запуск — по [README](../README.md), локальный адрес `http://127.0.0.1:8765`. Для restricted-стенда в «Подключение» указываются разрешённые `X-System-ID` и `X-API-Key`; ключ не сохраняется браузером. В показе используются только вымышленные значения. Сервис сам не отправляет текст во внешнюю LLM.

## Показ за 60–90 секунд

1. **0–20 с:** открыть «Карточка клиента», выбрать «Маска», нажать «Защитить текст». Показать скрытые значения, найденные типы и фактическое время ответа; нажать «Восстановить» и сравнить исходный текст, пробелы и знаки.
2. **20–40 с:** открыть «Контекст важен» и обработать публичного Пушкина и адрес банка. Затем ввести отдельную вымышленную карточку клиента: похожая по форме личная запись должна защищаться. Отрицательный пример проверяется живым результатом, а не обещанием.
3. **40–60 с:** переключить режим «Токены», защитить пример и показать типизированные замены. Для ответа LLM с переставленными/повторёнными токенами выполнить короткую API-проверку ниже.
4. **60–90 с:** показать один JSON-лог, `/metrics` и [схему](architecture.md), объяснить профиль правил/NER и один известный предел качества. Длительные нагрузочные тесты во время показа не запускать: их JSON уже сохранены.

Объяснение без технического фона: «Перед отправкой в модель мы заменяем личные фрагменты и сохраняем соответствие в закрытом хранилище. Модель работает с защищённым текстом, а разрешённая система получает обратно исходные значения. Правила, режим и возможность восстановления задаются для каждой системы. Неизвестные форматы могут быть пропущены, поэтому качество проверяется на отдельных корпусах; включённый компонент при отказе возвращает ошибку, а не успешный незащищённый результат».

## Проверка перестановки токенов

При restricted-запуске оператор заранее задаёт `SEIF_CLIENT_SYSTEM` и `SEIF_CLIENT_KEY` в защищённом окружении. `SEIF_URL` при необходимости меняет адрес. Код имитирует текст ответа LLM локально; внешнего запроса к модели здесь нет.

```bash
.venv/bin/python - <<'PY'
import os
import re
import uuid
import httpx

headers = {}
if os.getenv('SEIF_CLIENT_SYSTEM'):
    headers = {'X-System-ID': os.environ['SEIF_CLIENT_SYSTEM'],
               'X-API-Key': os.environ['SEIF_CLIENT_KEY']}
with httpx.Client(base_url=os.getenv('SEIF_URL', 'http://127.0.0.1:8765'),
                  headers=headers, trust_env=False, timeout=10) as client:
    request_id = uuid.uuid4().hex
    original = 'Email: judge@example.invalid; Телефон: +7 (900) 123-45-67.'
    response = client.post('/v1/mask', json={
        'payload': original, 'payload_id': request_id, 'mode': 'token'})
    response.raise_for_status()
    protected = response.json()['result']
    tokens = re.findall(r'⟦PD:[^⟧]+⟧', protected)
    assert len(tokens) >= 2
    print('Защищено:', protected)
    llm_reply = tokens[-1] + '\n' + tokens[0] + '\n' + tokens[-1]
    restored = client.post('/v1/unmask', json={
        'payload': llm_reply, 'payload_id': request_id})
    restored.raise_for_status()
    assert restored.json()['result'] == (
        '+7 (900) 123-45-67\njudge@example.invalid\n+7 (900) 123-45-67')
    print('Перестановка и повтор токенов: точное восстановление подтверждено')
PY
```

Контракт организатора проверяется отдельно: `POST /process` принимает `{payload,payload_id}`, возвращает ровно `{result}`; его результат отправляется вторым запросом с тем же ID. [Спецификация](../process_api.yaml).

## Логи и метрики

В локальном запуске JSON-аудит виден в консоли процесса (logging пишет в stderr); в Compose:

```bash
docker compose logs --tail=20 api
```

Показать событие `processed`: типы, режим, latency и `stages_ms`, без исходного текста, `payload_id` и ключей. При ошибке защиты демонстрируется контролируемый код ошибки; значение исходного текста не должно появляться в журнале.

`GET /metrics` находится на том же сервере и требует те же заголовки restricted-системы. В demo доступен без ключа. Показать `seif_http_requests_total`, `seif_http_duration_seconds`, `seif_stage_duration_seconds`, `seif_entities_total`. RPS — `rate(seif_http_requests_total[1m])`; TPS — `rate(seif_input_tokens_estimated_total[1m])`, **оценка characters/4**. Новая цель жюри — ≤0,5 с при 1000 RPS; фактические цифры по профилю и версиям находятся в [отчёте](validation.md), а не выводятся из настройки генератора.

## Настройки за пять предложений

1. Добавьте систему в `config/policies.yaml`, укажите `enabled` и имя переменной ключа в `api_key_env`.
2. Задайте ключ этой системы, общий `SEIF_MASTER_KEY` и Redis/Sentinel-настройки в окружении.
3. Выберите `masking_enabled`, `types`, режимы, `allow_unmask` и сочетания `min_types`/`required_types`.
4. Добавьте при необходимости ограниченные `extra_rules`, настройте `rps` и перезапустите процесс.
5. Передавайте `X-System-ID`/`X-API-Key`, используя новый `payload_id` на текст и прежний ID для восстановления и ретраев.

`enabled:false` запрещает обращение системы; `masking_enabled:false` сохраняет доступ и распознавание, но явно отключает замену, что отражается в ответе/аудите. Значение по умолчанию — `true`; `types:[]` означает все типы. Для проверки переключателя используйте новый `payload_id` после изменения настройки и вымышленные данные без отправки в реальную LLM. Это осознанное исключение потребителя; ошибки Redis/NER его не включают. [Точная формулировка критерия](judging-criteria.md).

## Бонусы с понятной пользой

- **Токены или синтетика:** модель получает структуру запроса без исходных личных значений; token допускает повтор и перестановку в ответе.
- **Режим по системе:** разные потребители выбирают разрешённую форму представления.
- **Другие документы:** ограниченные форматы семи соседних регионов; [перечень](cis.md).
- **Сочетание типов:** `card-support` маскирует при карте и втором типе, например PIN; это явно выбранная политика, а не общий режим защиты.
- **Повышенная нагрузка:** учитывается только подтверждённым прогоном соответствующего профиля при новом ориентире 0,5 с.

По техническому PDF уверенный показ любых трёх возможностей достаточен для максимума этого 3-балльного критерия; итог выставляет жюри. Для продолжения после хакатона подготовлен [план пилота](roadmap.md).
