# RPS локального GPU kind и публичного шлюза — 24.09.2026

Проверен HTTP `/process` с повторной отправкой полученной маски для точного
восстановления. Нагрузка открытая, без повторов после ошибки: 446 разных
организаторских текстов из `load-corpus.jsonl` (SHA256
`407f1090c19a1c7a7b763ba897fad6d5fd49da009502a9300d35ac715ec18b46`).
Исходные тексты и подробные JSON-отчёты лежат только в игнорируемых Git
`local-data/` и `output/kind-gpu-isolation/`.

Сервис: 3 API pod на Python 3.14.7t, 2 pod RuBERT TensorRT на RTX 4070 Ti
SUPER, 3 Redis/Sentinel pod, захват запросов включён. Публичный путь:
HTTPS на Cloud.ru VM (2 vCPU) → Caddy → обратный SSH → локальный шлюз kind.
`p95` ниже включает все предпринятые запросы, включая ошибочные; успешный RPS
делит число успешных ответов на всё время теста с ожиданием завершения.

| Путь | Предложено HTTP RPS | Длительность | Успешно HTTP RPS | Ошибки | Проверено пар | p95, мс |
|---|---:|---:|---:|---:|---:|---:|
| Вход в kind с localhost | 1000 | 10 с | 999,2 | 0 | 5000/5000 | 10,8 |
| Вход в kind с localhost | 2000 | 10 с | 1995,9 | 0 | 10000/10000 | 73,6 |
| Петля через SSH/VM, без HTTPS | 2000 | 10 с | 1674,0 | 102 | 9887/10000 | 638,0 |
| Прямой публичный HTTPS | 100 | 15 с | 97,0 | 2 | 748/750 | 235,7 |
| Прямой публичный HTTPS | 250 | 15 с | 242,4 | 9 | 1866/1875 | 216,6 |
| Прямой публичный HTTPS | 500 | 10 с | 417,1 | 23 | 2477/2500 | 754,7 |
| Прямой публичный HTTPS | 2000 | 5 с | 0 | 4625 | 0/5000 | 5957,0 |

На прямом публичном тесте 2000 RPS клиент успел начать 4625 из 10000
предложенных HTTP-запросов; остальные не были отправлены из-за переполнения
лимита параллелизма или пропуска срока. Из предпринятых было 4095 тайм-аутов
и 530 ошибок соединения. После теста публичный `/health` вернулся к HTTP 200.

**Вывод:** сам локальный kind выдержал 2000 RPS на этом корпусе и 10-секундном
окне. Публичный адрес такого результата не показал. Петля через SSH отдельно
дала ошибки при 2000 RPS; прямой HTTPS нестабилен и на меньших ступенях.
Точная доля ограничений SSH, TLS, VM и внешней сети этим набором тестов не
установлена. Нужен другой публичный транспорт или его масштабирование, а затем
повторный тест с тем же корпусом; нельзя переносить локальные 2000 RPS на
публичный SLA.

Локальные замеры выполнены неизменённым `scripts/benchmark_corpus.py`.
Для прямого публичного HTTPS использована временная копия того же скрипта с
добавлением **только** точного имени публичного хоста в список разрешённых
адресов; его штатный ограничитель допускает лишь localhost. SHA256 временной
копии: `67e476505b76c3e215aa952057bcffe88217d04e8d25d75b67b9e3124fe4b356`.
Копия не входит в поставку сервиса.
